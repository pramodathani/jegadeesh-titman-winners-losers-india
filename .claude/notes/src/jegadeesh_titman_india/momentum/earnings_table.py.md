# earnings_table.py

Day 0 is the announcement date if it is a session and the time is up to 15:30, otherwise the next session. The 3-day return compounds days -2 to 0 and needs trades on at least two of the three days. A winner-minus-loser difference is formed per ranking month and event month t, and the t-statistic comes from the spread across ranking months. Announcements run from 2007-08 to 2025-03 because NSE's results API thins out after that.
