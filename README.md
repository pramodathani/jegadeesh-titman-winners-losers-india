# Returns to Buying Winners and Selling Losers in India

A replication of Jegadeesh and Titman (1993) for Indian shares on NSE: the 32 J/K momentum strategies of their Table I, the paper's other tables where Indian data allows, and long-only versions an Indian investor could hold, measured after Indian trading costs against the NIFTY 500.

**In one line:** work in progress; no results yet.
